DER ERSTE START DAUERT.
Der initContainer holt {{ .Values.model.repo }} — rund 54 GB. Bis der Pod
bereit ist, vergeht die Ladezeit plus etwa 160 Sekunden fuer den Modellstart.
Jeder weitere Start ueberspringt den Download anhand einer Marke im Volume.

  kubectl -n {{ .Release.Namespace }} logs -f \
    -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=server \
    -c modell-holen
{{- end }}

Bereitschaft beobachten:

  kubectl -n {{ .Release.Namespace }} rollout status \
    deployment/{{ include "southbyte-music.fullname" . }}

{{- range .Values.ingress.hosts }}

{{- else if .Values.webui.enabled }}

    svc/{{ include "southbyte-music.fullname" . }}-webui 8080:{{ .Values.webui.service.port }}
