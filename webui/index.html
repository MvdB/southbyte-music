Text

[Intro] [Verse] [Chorus] [Bridge] [Outro] — jedes Tag auf eigener Zeile. Text daneben wird beim Normalisieren verworfen.
Der Beispieltext ist englisch, und das aus zwei Gruenden: das Modell singt BYTE in deutschem Umfeld wie „biet“, und deutsche Umlaute muessen man umschreiben, damit nichts verschluckt wird — was im Text dann seltsam aussieht. Deutsche Lyrics gehen trotzdem, wenn man damit leben kann.

Klangbild

Englisch schreiben. Alle Beispiele des Herstellers sind englisch; eine deutsche Caption zog das Ergebnis hoerbar in Richtung deutschsprachiger Popmusik, unabhaengig vom gewuenschten Genre. Die Lyrics duerfen deutsch bleiben.
Den Aufbau beschreiben, nicht nur das Genre. Das Beispiel ist die Langform: Global Metadata · Vocal Details · Arrangement. Gleiche Lyrics, gleiche Framezahl, nur die Form anders — die Streuung ueber zwei Seeds fiel von 0,325 auf 0,055, das Stereobild wurde von 0,46 auf 0,54 breiter. Jedes Abschnitts-Tag oben soll im Arrangement vorkommen.
Das Tempo ist ein Wunsch. Vier Laeufe mit ausdruecklich geforderten 150 BPM trafen sie in keinem Fall. Eine Spanne ist ehrlicher als eine Zahl, auf die man sich nicht verlassen kann.
Beide Formate kommen in Stereo zurueck: seit SGLang-Omni v0.1.3 leitet der Kodierer das Kanalbild aus den Daten ab, statt es fest auf Mono zu setzen. WAV bleibt die Vorgabe, weil es verlustfrei ist.
Gleicher Seed und gleiche Eingabe ergeben dasselbe Stueck.
